# Vim Terminal Mono Wide Icons

This font combines the DejaVu Sans Mono text glyphs with adapted file icons.
The icon outlines were remapped, scaled, and split into two adjacent
monospaced glyphs for use by NERDTree.

- The text glyphs come from [DejaVu Fonts](https://dejavu-fonts.github.io/).
  See [the DejaVu notice](DejaVu-Notices.txt) for the Bitstream Vera license
  and the public-domain status of the DejaVu changes.
- The file-type icons come from [Seti UI](https://github.com/jesseweed/seti-ui)
  by Jesse Weed under the MIT license. See [the Seti notice](Seti-Notices.txt).
- The folder, file-code, folder-symlink, and branch icons come from
  [Codicons](https://github.com/microsoft/vscode-codicons), copyright Microsoft
  Corporation, under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
